About this book

Alaska by Land & Sea 2027 is built on research, not reminiscence: reservation windows checked against the agencies that set them, real costs given as checkout totals, and the honest disqualifier alongside the recommendation. Every figure in the printed book was current at the time of writing — Alaska changes constantly, so the update page is how the book keeps up after it's printed.
